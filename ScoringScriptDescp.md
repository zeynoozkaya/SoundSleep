# **Scoring Scripts Overview**
Overview of final script with GUI used score muscle contractions in SoundSleep and functions used to train/test other methods. 

### **`contraction_classification_final.ipynb`** 
Script for scoring behavior responses during SoundSleep experiment using a combined human scorer/algorithm approach. 

### **`compare_models.ipynb`** 
This script implements three convolutional neural network (CNN) models for classifying muscle contractions. Using the DataFrame generated by `emg_feature_extraction.ipynb`, you can:

* Train the models
* Save the trained models
* Visualize and plot the training results

#### Available Models

##### Single-Head Count

Predicts the number of muscle contractions within a given epoch.

##### Single-Head Duration

Predicts the duration of the complete contraction period within a given epoch.

##### Two-Head Model

Simultaneously predicts:

* The number of muscle contractions within a given epoch.
* The duration of the contraction period within the same epoch.

### **`emg_feature_extraction.ipynb`**
This script loops through the raw EMG files, preprocesses the raw data, and extracts variance, WL, and RMS using a sliding window. The preprocessed data can be saved to an Excel file, and the results can be visualized with a GUI.

### **`emg_feature_extraction_soundsleep.ipynb`**
Same function as `emg_feature_extraction.ipynb` but targeted for the new data. 

### **`healthy_data_testing.ipynb`**
Tests models trained on narcoleptic patient data on unseen healthy participant data 

### Data sets 
**subj_healthy.pkl** : healthy participant data from feature extraction script

**training\_features_18042026.pkl** : healthy participant data from feature extraction scrip 

**trial\_info_duration\_1205.csv** : trial information including duration of contraction event

### Models 
**contraction.keras** CNN model trained on narcoleptic data set for contraction number based on single muscle channel. Can use to test healthy data.
